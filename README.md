# Запаси

Облік домашніх продуктів: сканування штрихкоду → підтягування назви й фото з
OpenFoodFacts → контроль термінів придатності → список покупок. PWA, працює офлайн,
дані зберігаються лише на пристрої.

## Команди

```bash
npm install
npm run dev        # dev-сервер на http://localhost:5173/stock/
npm run dev -- --host   # щоб відкрити з телефона в тій самій мережі
npm test           # тести (vitest)
npm run typecheck  # перевірка типів
npm run build      # продакшн-збірка у dist/
npm run preview    # перегляд продакшн-збірки локально
npm run deploy     # публікація на gh-pages
```

> Камера в браузері працює лише через HTTPS або на `localhost`. Щоб перевірити сканер
> із телефона, потрібен `vite --host` разом із тунелем на HTTPS — або просто відкрити
> задеплоєну версію.

## Структура

```
src/
  db/         Dexie: схема, міграції, репозиторії, бекап
  hooks/      робота з даними, пошук товару за штрихкодом, сканер, сповіщення
  features/   inventory / shopping / settings — по одній сторінці на вкладку
  components/ спільні елементи інтерфейсу
  utils/      дати, CSV
  i18n/       українські підписи
```

## Дані

Усе лежить в IndexedDB браузера (база `stock`), нічого не надсилається на сервер.
Єдиний зовнішній запит — до OpenFoodFacts за назвою та фото товару за штрихкодом.

**Схема версіонована через Dexie.** Версія 1 навмисно лишається в `src/db/index.ts`:
без неї бази, створені старою версією застосунку, не знайшли б шляху міграції на
версію 2 і дані було б втрачено. Міграція нормалізує типи (кількість із рядка в число,
порожній термін у `null`) і дозаповнює нові поля; жоден запис не видаляється.

Резервні копії робляться вручну в «Налаштуваннях» — JSON (повний бекап із можливістю
відновлення) і CSV (для таблиць). Очищення даних сайту в браузері стирає базу, тож
експорт варто робити час від часу.

## Обмеження

Сповіщення про терміни придатності приходять при відкритті застосунку, не частіше разу
на добу, плюс бейдж із кількістю термінових товарів на іконці. Надсилати сповіщення у
фоні, коли застосунок закритий, без сервера технічно неможливо — для цього потрібен
push-сервіс.
